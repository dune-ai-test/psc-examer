What it does

Less copying. More recalling.

Built around the way printed PSC papers actually reach you — a photo, a photocopy, a friend’s notes. Padanam handles the transcribing so you can get to the revision.

01

Camera-first capture

Single page, a multi-page set of up to eight shots, or batch import from your gallery. Focus, flash and lens flip are handled by CameraX.

02

Gemini does the typing

Each stem, four options, the correct letter and a short explanation come back in both languages — validated and normalised before they reach your library.

03

A quiz you can read both ways

Switch between English and Malayalam mid-question. Only the question content changes; the app chrome, timer and progress stay exactly where they were.

04

Practice or full mock

Pick a question count and a clock, flag anything you want to revisit, and resume an active exam even after leaving the app — the countdown keeps running.

05

Scores that never disappear

Every attempt saves a snapshot of its questions, your answers and the explanations in Room. Delete a set later and your history still opens, intact.

06

Optional Neon backup

Mirror your library and attempts to your own Postgres database. Sync manually, or automatically after every saved scan and submitted attempt.

The workflow

Three steps, then it’s yours.

No typing, no spreadsheet, no photograph lost in the gallery. A clear page becomes a quiz set in a few seconds.

  1. 01

    Capture

    Frame the page, or bring in up to eight photos. Images are downsampled to 1600 px and rotated from EXIF before upload.

  2. 02

    Extract

    Gemini reads both scripts, pairs every stem with options A–D, infers the answer and writes a bilingual explanation.

  3. 03

    Practise

    Check the confidence, then start a practice set or a timed mock. Revision is fully offline; syncing is your call.

Questions

The short answers.

Everything about the build, the keys and where your data sits. More detail lives in the project README.

Is Padanam on the Play Store?

No. It is a personal project shipped as a debug APK from GitHub Releases. A workflow builds app-debug.apk on every push to main and publishes it as a pre-release.

Do I need a Gemini API key?

Yes, for scanning. Paste a key from Google AI Studio in Profile → Settings (or bake one in at build time). The built-in demo set and any questions you have already saved work without it.

Does it work offline?

Revision does. Scanning needs Gemini and syncing needs Neon, but Room is the source of truth: saved sets, mock exams and per-question review all work in airplane mode. An active exam keeps counting while the app is backgrounded.

Where do my scores go?

Into Room on the device, first. If you add a Neon connection string, library rows and attempt snapshots are also mirrored to your own Postgres database — automatically when auto-sync is on, or via Settings → Sync now.

Is my data private?

There is no account and no analytics. Photos are sent only to Gemini for extraction, and Neon receives only what you choose to sync. One caveat: if you compile API keys into the APK through local.properties, anyone with the APK can extract them. Prefer entering keys at runtime in Settings.

Can I use it on an iPhone?

No. Padanam is a native Kotlin and Jetpack Compose app for Android 8.0 (API 26) and newer. The three-question demo above is the only web part.

How do I update to a newer build?

Download the newest APK from the releases page and install it over the existing app. Local data is preserved as long as you do not uninstall first. Builds are signed with the same debug key, so Android treats them as an update.

Why does Android warn me about the APK?

It is a debug build, signed with a debug certificate and distributed outside the Play Store. Android shows the standard “unknown apps” warning. Install only from the release page above.
